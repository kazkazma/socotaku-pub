## 認識 socotaku-pub

socotaku-pub 是一套命令列排版工具，目標是將 Markdown 稿件自動轉換為符合傳統中文直排格式的 PDF 檔案。本工具採用 TypeScript 搭配 Bun 執行環境開發，內建三種常見的書籍版型，適用於評論集、散文集與其他以純文字為主的出版品。

與 Adobe InDesign 等通用排版軟體不同，socotaku-pub 並不追求無所不包的排版功能，而是針對已知的版型規格提供全自動化的排版流程。使用者只需撰寫 Markdown 格式的稿件，加上少量的 HTML 註解指令，就能在數秒內產出一份排版精良的 PDF。這個設計的核心，是將設計師從重複性的版型調整工作中解放出來。[^1]

## 為什麼需要自動化排版

傳統的書籍排版工作高度依賴人力。設計師需要在 InDesign 中逐頁調整字距、行距、欄位配置，一本兩百頁的書可能需要數週甚至數月的排版時間。而這個過程中，大部分的操作其實是重複性的：設定版心尺寸、放置文字框、調整段落樣式、處理腳註位置。這些工作的本質是規則驅動的反覆運算，非常適合由程式來自動化處理。

自動化排版並非全新的概念。早在金屬活字時代，排版工人就遵循著嚴格的規範來安排版面上的每個字元。數位時代的 Donald Knuth 更以 TeX 系統證明了，在明確定義的規則之下，電腦能夠產出媲美甚至超越人工的排版品質。socotaku-pub 繼承了這個精神，並將目標鎖定在中文字型的直排書籍領域，希望為中文出版社群提供一套輕量而可靠的自動化解決方案。[^2]

## 三大設計原則

socotaku-pub 的開發圍繞三個核心原則：簡潔、精確、可重複。這三個原則貫穿了從架構設計到程式實作的每一個環節。

第一是簡潔。使用者只需要學習 Markdown 語法和三個 HTML 註解指令——版面切換、分頁、分欄——就能完成整本書的排版。所有排版參數諸如字型、字級、行距、邊距都已經預先封裝在版型樣板中，使用者不需要也不能在稿件中隨意調整。這種限制設計確保了整本書的視覺一致性，也大幅降低了學習成本。使用者不必成為排版專家，就能產出專業水準的稿件。[^3]

第二是精確。排版引擎在 Chromium 瀏覽器環境中執行，利用 CSS 的 writing-mode 屬性以 vertical-rl 模式模擬傳統中文直排。每個字元的位置由引擎動態計算，字距與行高達到了印刷等級的精確度。尤其在標題與正文的關係處理上，引擎會自動避免「孤兒標題」——亦即標題獨自留在頁面最下方而內容盡數跳到下一頁的排版瑕疵。

第三是可重複。因為整個排版過程是純粹的程式邏輯，沒有任何人為的手動干預，同一份稿件在任何時間執行都會產出完全相同的結果。對於需要反覆校稿、多次修改的出版流程來說，這項特性極為重要。每一次改稿之後，只需重新執行一次命令列指令，就能在數秒內得到最新版本的完整 PDF。

## 技術架構：四階段處理管道

socotaku-pub 的處理流程分為四個階段：解析、排版、渲染、輸出。第一階段的解析器使用 remark 生態系統將 Markdown 內容轉換為節點串流。段落、標題、腳註引用、腳註定義都被提取為結構化的資料。同時，HTML 註解中的排版指令也會在這個階段被識別並納入節點串流。第二階段的排版引擎將這些節點分配到各頁的各欄位中，並在空間不足時自動進行文字拆分與跨欄跨頁流動。第三階段的渲染器將每頁的節點資料轉換為 HTML，搭配預先載入的版型 CSS，在瀏覽器中呈現最終的視覺樣貌。最後，輸出階段透過 Puppeteer 操控 headless Chromium，將 HTML 頁面輸出為可直接送印的 PDF 檔案。這四個階段形成了一套完整的自動化生產線，從輸入到輸出無需人工介入。[^4]

## 結語

socotaku-pub 目前仍處於開發階段，但核心管道已經可以完整運作。我們期待這個工具能夠降低書籍排版的門檻，讓更多作者能夠輕鬆地將自己的文字轉化為精美的印刷品。排版工具的價值不在於功能的多寡，而在於它能否有效解決實際的問題。對於以純文字為主的評論集而言，Markdown 進、PDF 出這個工作流程，正是最直覺而高效的解決方案。
