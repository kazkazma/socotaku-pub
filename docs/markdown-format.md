# Markdown 稿件格式

## 文件目的

本文定義 `content/*.md` 作為刊物稿件時，作者與編輯可以依賴的外部格式契約。

本文件不是完整 Markdown 語法說明，而是描述本專案目前支援、建議使用與未來可能擴充的稿件格式。

## 基本規則

- 稿件放在 `content/` 目錄下。
- 稿件副檔名需為 `.md`。
- 多個 Markdown 檔案會合併成單一刊物。
- 檔案之間會自動插入分頁。
- 稿件中的排版控制以 HTML 註解形式的指令表示。

## 文章順序

目前文章順序由 `content/*.md` 的檔名排序決定。

建議以數字前綴控制順序，例如：

```text
01_第一篇文章.md
02_第二篇文章.md
03_第三篇文章.md
```

## 穩定支援內容

目前可作為穩定稿件格式使用的內容包含：

- 標題：`#` 至 `######`
- 一般段落
- 引用：`>`
- 圖片：`![](path)`
- 註腳：`[^1]`
- 粗體：`**文字**`
- 斜體：`*文字*`
- 換行：`<br>`

## 圖片

圖片使用標準 Markdown 圖片語法：

```md
![](img/example.png)
```

圖片路徑相對於該 Markdown 檔案所在目錄解析。

目前圖片主要搭配含有 `pic` 欄位的版型使用。若目前版型沒有圖片欄，圖片不應被視為可穩定輸出的內容。

## 註腳

註腳使用 Markdown 註腳語法：

```md
正文內容。[^1]

[^1]: 註腳內容。
```

建議註腳 id 使用數字，例如 `[^1]`、`[^2]`。

多個 Markdown 檔案合併時，系統會在內部避免跨檔案註腳 id 衝突；輸出顯示仍保留原本的註腳編號。

頁下注是主要註腳形式。尾注或 endnote 頁面可透過對應版型支援。

## 排版指令

排版指令使用 HTML 註解表示。

### 切換版型

```md
<!-- layout: layout-a -->
```

切換後續內容使用的版型。版型名稱需對應 `templates/layout-*.html` 的檔名。

例如 `templates/layout-a.html` 對應的版型名稱為 `layout-a`。

### 強制分頁

```md
<!-- page-break -->
```

強制結束目前頁面，後續內容從新頁開始。

### 強制分欄

```md
<!-- column-break -->
```

強制移動到下一個正文欄。若目前已位於最後一個正文欄，則後續內容從新頁開始。

## 局部樣式

可使用 `style` 指令對下一個段落或引用套用局部 CSS：

```md
<!-- style:"padding-top:3em; text-indent:-3em;" -->
> 引用內容
```

`style` 是正式支援的排版修補功能，但定位是局部調整。

若內容需要穩定重複使用的特殊排版、圖片欄或頁面結構，應優先新增或調整版型，而不是依賴大量 `style` 指令。

## 建議寫法

- 使用檔名排序控制文章順序。
- 每篇文章開頭明確指定初始版型。
- 圖片頁、特殊欄位與特殊結構優先透過版型處理。
- 局部微調才使用 `style` 指令。
- 註腳 id 優先使用數字。
- 避免在正式稿件中依賴未列為穩定支援的 Markdown 結構。

## 目前不視為穩定支援

以下內容目前不應作為穩定出版輸出依賴：

- 有序與無序列表
- 表格
- Markdown 超連結
- 除 `<br>` 外的 inline HTML
- 圖片 slot 指定
- 正文流圖片
- 非數字註腳 id

其中部分項目已列入未來支援方向，但在尚未正式實作與驗證前，不應作為稿件格式契約。

## 未來方向

### 列表

未來應支援有序與無序列表。

列表應保留語意，具體視覺呈現由 CSS 與版型決定。

### 表格

表格是近期支援方向。

優先方向是產出 HTML 表格；若直排測量、版面控制或輸出穩定性不佳，可能評估改以 SVG 產出。

初期表格可先作為獨立區塊處理，不參與正文欄流動。

### 圖片 Slot

未來應支援指定圖片 slot，使圖片可被送入特定圖片欄或版型區域。

偏好的語法方向是延續現有 HTML 註解 DSL：

```md
<!-- image-slot: pic -->
![](img/example.png)
```

這種寫法可以讓未加入排版 patch 的稿件仍然維持標準 Markdown 圖片語法。

### 正文流圖片

未來可考慮支援正文流圖片。

正文流圖片會作為正文欄中的獨立區塊排入，位於前後文字段落之間，並佔用正文欄空間。這不同於圖片 slot 行為，圖片 slot 是將圖片送入版型指定的圖片欄或區域。

### Inline HTML

除 `<br>` 外，其他 inline HTML 目前不視為穩定支援。未來預計以白名單方式逐步支援常見樣式型 inline HTML。

預計評估的標籤包含：

- `<span>`
- `<ruby>`
- `<rt>`
- `<em>`
- `<strong>`
- `<small>`
- `<u>`
- `<mark>`
- `<sup>`
- `<sub>`
- `<del>`
- `<code>`

其中 `<span>` 預期可支援 `class` 與 `style`，作為局部排版修補、偽內容與版型 hook 使用。

### Markdown 超連結

Markdown 超連結在紙本輸出中的處理方式保留待討論。

可能方向包含僅保留連結文字、顯示 URL、轉成註腳或轉成參考資料格式。

### 稿件 Metadata

稿件層級 metadata 保留待討論，目前不列為支援功能。

未來可能方向包含：

- YAML frontmatter
- 貼近現有排版 DSL 的 HTML 註解

metadata 可用於描述標題、作者、預設版型、註腳策略等稿件層級資訊。
